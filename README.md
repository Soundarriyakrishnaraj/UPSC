# UPSC Preparation App

A Flutter-based UPSC Civil Services Examination preparation application.

## Features

- Student registration and login
- User profiles and preferences
- Previous Year Question Papers
- Prelims and Mains preparation
- Question papers and answer keys
- PDF viewing and downloads
- Admin panel for managing study materials
- Supabase backend integration

## Technologies

- Flutter
- Dart
- Supabase
- PostgreSQL

## Getting Started

Install Flutter and configure the Android development environment.

Get project dependencies:

```bash
flutter pub get
```
